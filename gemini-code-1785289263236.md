## 🎯 Project Objective
Build an end-to-end Analytics Engineering portfolio project utilizing simulated Workday HR data. *   **IDE:** VS Code (Mac environment)

**The Cause:** dbt generated a default empty database (`dev.duckdb`) inside the dbt folder because the `profiles.yml` file was not pointing to the correct absolute path of the existing database.
**The Fix in Progress:** The user needs to edit `~/.dbt/profiles.yml` to point the `path` variable to the actual database: `/Users/yuchitsai/Documents/people-analytics-dbt-pipeline/people_analytics.duckdb`.
